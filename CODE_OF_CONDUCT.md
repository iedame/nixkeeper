# Code of conduct

nixkeeper is made for the Nix community, and follows its code of conduct:
the [NixOS community's Code of Conduct](https://github.com/NixOS/.github/blob/master/CODE_OF_CONDUCT.md)
applies to everyone taking part here, in issues, pull requests,
discussions and anything else in the [nixkeeper organisation](https://github.com/nixkeeper)
on GitHub.

## Reporting

Report behaviour that breaks it to the project's maintainer,
[@iedame](https://github.com/iedame), privately: what happened, where, and
links if you have them. Reports are kept confidential. GitHub's "Report
content" (on any comment, issue or discussion) also reaches GitHub's own
moderators.

The maintainer may remove, edit or reject comments, issues, pull requests
and discussions that break the code of conduct, and block a participant
from the organisation, temporarily or for good, as the NixOS code of
conduct's enforcement describes.
