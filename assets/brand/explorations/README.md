# Wordmark explorations

Snapshots from choosing the wordmark (October 2026), kept to revisit the
choice later. Each page is self-contained: open it in a browser (the
candidate sheet loads its fonts from Google Fonts). `nix run .#brand` doesn't
touch them.

| Page | What it shows |
| --- | --- |
| `wordmark-candidates.html` | 18 open-licence typefaces next to the mark, on light and dark, with toggles for weight, sizing (cap height or x-height), tracking and theme |
| `wordmark-finalists.html` | Oxanium and Chakra Petch at 700, outlined, x-height = 0.42 of the mark |
| `wordmark-case.html` | Both finalists as "nixkeeper" and "NixKeeper" |

The choice: Oxanium Bold, lowercase "nixkeeper", sized by x-height. See
`../BRAND.md` for the rules, and `scripts/brand/wordmark.py` for how the
lockups outline it.
