# nixkeeper brand

nixkeeper is a health dashboard for the nixpkgs packages a maintainer looks
after: new releases, build and update failures, and vulnerabilities, in one
place. Its identity uses the system of the NixOS Branding Guide v0.1.0 (its
geometry, its tint recipe, its accent colours) with nixkeeper's own mark,
colours and typeface, so it reads as part of the Nix ecosystem without looking
like the NixOS logo or an official NixOS project.

nixkeeper is a community project, not affiliated with the NixOS Foundation.

## Files

Everything here is generated by `scripts/brand/` (`nix run .#brand`, see
CONTRIBUTING.md): edit the scripts, not these files.

- `nixkeeper-mark.svg`: the mark with its clearspace. `favicon.svg`: the
  mark cropped tight (also the page's favicon, copied to `docs/`).
- `nixkeeper-mark-*.svg`: the variants (flat, black, white on black,
  rainbow).
- `nixkeeper-status-*.svg`: the status versions (see "Status icon").
- `nixkeeper-lockup*.svg`: the mark with the name, light and dark.
- `tokens.css`, `tokens.json`: colours and fonts. Use these rather than
  hard-coding hex values.
- `identity.html`: the identity sheet; open it in a browser.

## The mark

A flat-top hexagonal ring of three chevrons turning around a solid centre
hexagon: the maintainer's package (the centre), guarded (the ring), with the
three signals nixkeeper watches (the chevrons).

- Outer radius R, inner ring R/2, centre R/4: each half the one before, the
  guide's "recursive form". The gap between chevrons is R/32, like the
  guide's lambda.
- All angles are 60° or 120°.
- Chevron 1 (top right) = new releases, chevron 2 (left) = build and update
  failures, chevron 3 (bottom) = vulnerabilities.
- Colours: each chevron runs from violet to mauve, with stops at 0%, 25% and
  100% as the guide's gradient: `#534b89` (0%), `#6156a3` (25%), `#c29dd7`
  (100%). The centre is `#6156a3`.

The two colours follow the contrast recipe of the NixOS logo's two blues: the
light end is lighter (OKLCH L 0.50 → 0.75), less saturated (C 0.12 → 0.09)
and turned 25° in hue (288° violet → 313° mauve). That's what makes them read
as two colours, not one colour in two shades.

Variants: gradient (the default), flat (`#6156a3`, for print), black, white on
black, and rainbow (pride). Black and white are always flat.

## The page's colours

The dashboard's colours keep the meanings the page already has (see "Reading
the page" in the README); each is one of the guide's accents.

| Meaning | Role (tokens) | Colour |
|---|---|---|
| up to date | `ok` | Zambian Green |
| outdated, a new release | `outdated` | Persian Orange |
| failed, not in nixpkgs, vulnerable | `failed` | Norwegian Pink |
| can't update, marked broken | `warn` | Indian Gold |
| on master (merged, waiting for the channel) | `merged` | brand violet |
| links and key UI | `link` | brand violet |
| text, lines, backgrounds | neutral | the guide's greys |

Each role has four values per theme, from its ramp (the guide's tints, L95 to
L15):

| Use | Light theme | Dark theme |
|---|---|---|
| `fill`: dots, icons | L65 | L75 |
| `text`: labels, counts | L45 | L75 |
| `badge`: badge backgrounds (white text) | L55 | L55 |
| `bg`: tinted backgrounds | L95 | L25 |

The L75 accents aren't readable as text on white, which is why light-theme
text uses L45, and white text needs a badge at L55 or darker in either theme
(L65 falls below the 4.5:1 contrast minimum). Failures and vulnerabilities share the pink: labels tell them
apart on the page, and on the mark, which chevron turns. Never rely on colour
alone for a status: pair it with a label or an icon.

## Status icon

The mark doubles as a status indicator (favicon, tab icon): when a signal is
active, its chevron turns to that signal's page colour, and the rest stays
violet. New releases turn orange; failures and vulnerabilities turn pink.
When all is well, the releases chevron turns green instead ("up to date"),
like the page's green.

| State | Version | Chevron |
|---|---|---|
| all good | `nixkeeper-status-ok.svg` | releases (top right), green |
| a new release | `nixkeeper-status-release.svg` | releases (top right), orange |
| a failure | `nixkeeper-status-failure.svg` | failures (left), pink |
| a vulnerability | `nixkeeper-status-vuln.svg` | vulnerabilities (bottom), pink |

Use the status versions only where the mark shows state (the favicon); use
the plain mark everywhere else.

The page's tab icon is live: it lights each chevron whose signal is active,
so several can show at once. `favicon-<signals>.svg` are those icons, cropped
tight like `favicon.svg`, one per combination: `favicon-ok.svg` (all good),
then `r` (a new release), `f` (a failure), `v` (a vulnerability) and their
combinations, e.g. `favicon-rf.svg`. Inactive chevrons stay violet.

## Typography

- The page and the wordmark: Instrument Sans (the wordmark in Bold, always
  lowercase: "nixkeeper"). Not Route 159, the NixOS logotype's typeface.
- Versions and code: JetBrains Mono.
- The lockups use live text; convert it to outlines before publishing them.
  The wordmark's cap height is half the mark's height, and the gap between
  mark and name is 3/8 of the cap height.

## Usage

- Clearspace: recommended = the mark's height, minimum = half of it.
- Minimum size: 24 px on screen, 6 mm in print. At 16 px (favicons) the gaps
  close up, but the ring and its centre still read.
- Don't rotate, mirror, distort or crop the mark, recolour the centre, or
  place it on similar violets.
- Don't pair the mark with the NixOS logo or logotype, or present nixkeeper
  as an official NixOS project.
